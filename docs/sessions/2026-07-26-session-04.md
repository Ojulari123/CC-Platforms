## Done this session
1. **ERD** — `docs/erd.md`: identity (built) + Pulse (now built), Mermaid, with
   the cross-service-by-id rule drawn explicitly.
2. **Fix** `JWT_ISSUER` default → `cyphercrescent-identity`.
3. **Fix** `accept_invite` → clean 409 (pre-check + rollback-on-IntegrityError).
4. **Password reset** — `POST /auth/forgot-password` (always 204, no enumeration;
   503 only on global email misconfig) + `POST /auth/reset-password` (single-use
   hashed token, expiry, bumps `token_version`, revokes refresh tokens). Table
   `password_reset_tokens` (migration `0007`).
5. **Shared pagination** — `crescent_core.pagination` (`Page[T]`, `PageParams`,
   `page_params`); members list gained `role` / `team_id` / `q` filtering.
6. **Token `leads` claim** — identity now carries the team ids a user leads;
   `crescent_core` parses it (`claims.leads`, `leads_team`). Backward-compatible.
   This is the seam that lets Pulse route approvals statelessly.
7. **Pulse service** — `services/pulse/`: own `pulse` DB, Alembic (`0001`), auth
   via `packages/core`, routes→services→data-access, `Page`-based listing,
   Docker + compose + two CI jobs. Domain: draft → submit → approve/reject/
   request-changes, append-only `approvals` history, flat `comments`.
